ReSkate VR
==========

ReSkate with experimental OpenXR VR: ride skate. in first person in a PC VR headset.
It is ReSkate itself plus the VR addon, built from the same release, so it plays with
everyone else on that ReSkate version (same servers, same mods).

Install
- Unzip into an empty folder of its own (not Steam's skate. folder) and run ReSkateLauncher.exe.
  The launcher downloads the supported game build, as ReSkate's does.
- Already have ReSkate in a folder? Unzip over it; your profile and mods stay.

Updates
- Leave the launcher's updates on. It updates from the ReSkate VR releases, which are rebuilt
  automatically for each ReSkate release, so you get ReSkate's updates with VR included.
- Right after a ReSkate release there may be a short wait until its VR build is out.

Using VR
- Start your headset's PC VR app first (Virtual Desktop, Meta Horizon Link, SteamVR).
- In game: open the ReSkate menu, HOME > VR, or ADDONS > VR for the settings
  (console: vrmenu). RECENTER on HOME, F8, or hold both stick clicks.
- Turn frame generation off and V-Sync off. A square resolution (2592 or 2880) looks best;
  square sizes are offered when the launcher starts windowed.
